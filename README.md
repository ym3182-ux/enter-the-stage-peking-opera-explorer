# Enter the Stage

An HTML/CSS prototype of a visual Peking Opera role explorer for international beginners. The page frames learning as a fictional first evening at a Shanghai theatre inspired by Tianchan Yifu Theater.

## Run locally

Open `docs/index.html` in a web browser. No installation is needed. The same folder is prepared for GitHub Pages.

## Current interaction

The prototype uses CSS-only radio selections to let visitors choose a role and respond to a stage cue. A future JavaScript version could add changing questions, supportive feedback, and learning progress.

## Structure

- `docs/index.html` — semantic page structure and learning content
- `docs/style.css` — theatre-inspired visual system, responsive layout, and CSS interactions
